# Maintenance Page

A clean and simple maintenance page for Stux.Design.

## Overview

This repository contains a lightweight HTML page designed to inform users of ongoing maintenance on a Stux.Design service. It's perfect for keeping users informed while work is being carried out.

Like its siblings it's a single static page, but drawn as a designer's artboard: a faint layout
grid, rulers along the edges, a selection box around the headline's highlighted words (tagged
"Redrawing") and crop marks on the card, all in Stux.Design magenta (`#e71081`).

## Features

- 📄 Simple, clean HTML structure
- ⚡ Lightweight and fast-loading
- 🎨 Ready to customize
- 📱 Responsive design
- 🚀 Deployed at [maintenancepage.stux.design](https://maintenancepage.stux.design)

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/StuxDesign/maintenancepage.git
   ```

2. Run `./dev-server.sh` (or `dev-server.bat` on Windows) and open `http://127.0.0.1:8000`.
   DEV_MODE is on by default, so the dev banner shows; pass `--no-dev-mode` to see the page as
   production does

## Customization

Edit the HTML files to:
- Update the maintenance message
- Add your branding and logo
- Customize colors and styling
- Include contact or status links

## Deployment

This project uses GitHub Pages and can be automatically deployed to your desired domain.

The live version is deployed at [maintenancepage.stux.design](https://maintenancepage.stux.design).
